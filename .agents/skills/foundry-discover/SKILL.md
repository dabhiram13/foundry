# Discover

Read `docs/WORKFLOW.md` first. Research only the uncertainties that block a product decision. Record sources, user problem, alternatives, constraints, and a recommended next slice under `docs/project/`; distinguish evidence from inference. Use `scripts/foundry.py` for lifecycle state; do not handcraft state or receipts.
