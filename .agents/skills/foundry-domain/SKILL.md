# Domain

Read `docs/WORKFLOW.md` first. Check candidate names against the product, trademark risk signals, and current domain availability using authorized search tools. Present candidates and evidence; do not purchase or register anything without explicit authority. Use `foundry work status --project PATH`, `foundry work start SLUG --spec PATH --project PATH`, and explicit `foundry work verify`/`complete` commands for scoped work. Never hand-edit `.foundry/state`.
