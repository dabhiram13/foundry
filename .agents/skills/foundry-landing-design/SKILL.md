# Landing Design

Read `docs/WORKFLOW.md` first. Derive one clear audience, promise, proof sequence, and call to action from product evidence. Implement with existing components and tokens, then verify mobile layout, semantics, performance, and the real conversion path. Use `scripts/marketcraft.py` for lifecycle state; do not handcraft state or receipts.
