# Setup

Read `docs/WORKFLOW.md` first. Detect the actual stack before configuring services. Ask before spending money, connecting accounts, publishing, or writing external systems. Use provider instructions from `library/skills/` as references, not as harness commands. Record setup decisions in project documentation and add executable checks to `.foundry/project.json`.
