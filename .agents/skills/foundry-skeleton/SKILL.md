# Skeleton

Read `docs/WORKFLOW.md` first. Work in an existing repository or create only the smallest independently authored local starter needed by the accepted spec. Do not fetch a vendor skeleton or invoke vendor CLIs. Prefer platform tools already present, preserve licenses, and configure real checks in `.foundry/project.json`.
