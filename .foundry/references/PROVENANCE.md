# Catalog provenance

The initial catalog was migrated from the locally delivered BuildThisNow CodeKit 0.3.0 framework. The delivered framework documentation identifies that framework as MIT licensed. Product Foundry preserves its source recipes as reference data and rewrites the active lifecycle for Codex.

The 60 shared skills have mixed provenance recorded in `skills-lock.json`. Vendored license files remain beside their material. Seven optional additions came from the delivered `.agents/skills` tree. Do not infer that every item was authored by one party; inspect the lock and local license files before redistribution.

The separately advertised SaaS skeleton is not included. It has separate restrictive terms and is not required by Product Foundry.

Operational state, credentials, home-directory configuration, vendor session hooks, license checks, and vendor CLI/backend code are not part of the active catalog.
