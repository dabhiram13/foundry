# UI Pattern

Opinionated default for this kit:

- Premium, clear, restrained.
- Strong hierarchy beats visual noise.
- Use the design system before inventing a new visual language.

Judgment: `.foundry/philosophy/visual.md` and `async-state.md`.

## Defaults

- Start from the existing tokens, spacing, and component patterns.
- One dominant action per area.
- Use contrast, spacing, and type scale before adding decoration.
- Mobile is not a later pass.
- Empty, loading, and error states are part of the design, not cleanup work.

## Smells

- Generic card grids with no hierarchy.
- Too many competing accents or gradients.
- Layouts that look desktop-first and collapse badly on mobile.
- Visual variation without product meaning.
- Polished happy path, weak edge states.
