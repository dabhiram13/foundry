# Step 3: Components and copy

Read AGENTS.md, docs/WORKFLOW.md, the adopted product brief, and the applicable
artifact contracts before acting. Follow the actual stack, assigned write paths,
and existing authority. These steps are options for the current scope, not a
mandatory full redesign. The adopted brief overrides generic visual recipes.

Implement the components required by the adopted prototype and design direction.
Preserve existing primitives and interfaces. Inspect affected callers before
changing a shared button/card/input. Avoid new dependencies unless separately
needed and authorized.

Use realistic content and meaningful labels. Cover keyboard/focus, disabled and
pending actions, validation, errors, empty results, success, and recovery when
applicable. Support target widths and content variation. Use motion or elevation
only when the adopted design calls for it. A flat control is not a failure.

Hand off changed files, states, copy decisions, criteria, and rendered/test evidence.
Do not claim mental layout review as responsive verification.
