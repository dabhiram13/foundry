# Step 4: Optional logo work

Read AGENTS.md, docs/WORKFLOW.md, the adopted product brief, and the applicable
artifact contracts before acting. Follow the actual stack, assigned write paths,
and existing authority. These steps are options for the current scope, not a
mandatory full redesign. The adopted brief overrides generic visual recipes.

Skip this step unless a logo or brand update is part of the request. Preserve an
existing mark otherwise. Use the approved direction and owned assets; retain
source/license notices and do not imply an asset's rights were cleared by a model.

Create or adapt only the requested deliverables using available authorized tools.
Check legibility at actual UI sizes and in supported themes/backgrounds. Keep
accessible names meaningful and decorative duplicates hidden appropriately.
Record the chosen asset, source, decisions, and usage. Tool absence is a blocker,
not permission to install or subscribe.
