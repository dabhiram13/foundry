# Step 6: Record the adopted system

Read AGENTS.md, docs/WORKFLOW.md, the adopted product brief, and the applicable
artifact contracts before acting. Follow the actual stack, assigned write paths,
and existing authority. These steps are options for the current scope, not a
mandatory full redesign. The adopted brief overrides generic visual recipes.

Update the owning design document rather than creating competing sources. Record
purpose, direction, token/component locations, copy conventions, interaction
states, target devices, supported themes, accessibility behavior, and exceptions
that the product actually adopts. Use links and concise examples.

Connect the design artifact to upstream flows/prototype and downstream criteria.
Identify changed contracts and stale handoffs for the coordinator. Keep proposals
separate from owner decisions. Settle these writes before final verification;
documentation is not a passing test receipt or owner acceptance.
