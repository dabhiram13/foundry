# Foundry

<!-- impeccable:product-schema 1 -->

## Platform
web

## Product purpose
Help the owner turn an idea into a working product on their computer. Install
and launch from the terminal; use the local browser workspace to describe work,
review plans and designs, and inspect code and test results.

## Capabilities and constraints
- Research → Plan → Design → Build → Test → Ship. Plan and Design need approval.
- Build uses small tasks, checks, limited repairs and Git checkpoints.
- Ship summarizes results. It does not publish or deploy.
- Codex is the built-in runtime. Other providers require qualified integrations.
- Source installation needs macOS/Linux, Python 3.11+ and Git; AI work also needs
  Codex and an explicitly confirmed subscription login.
- Files stay local; cloud AI providers receive prompts and selected content.
- Local fixture tests do not prove successful live AI execution or billing.

## Brand commitments
Original Foundry identity and specialist portraits. Plain language. The owner
selected Superset as the reference for a complete dark visual replacement;
previous Soft studio styling is no longer a constraint. Do not copy Superset's
mark, wording, customer claims or unsupported features.

## Evidence on hand
The actual React app, framework tests and local simulated-provider browser
journeys. Landing walkthrough content must be labeled as an example, not a
record of a live AI run or customer result.

## Accessibility
Keyboard access, visible focus, responsive layouts, readable contrast and
reduced motion. No account connection or AI spending as a side effect of browsing.
