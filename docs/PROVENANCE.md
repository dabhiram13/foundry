## Earlier public-site assets

The current warm site takes composition and interaction references from
[LightSprint](https://lightsprint.ai/) and its public docs: textured product
framing, an orange accent, compact controls and a selectable workflow. No
LightSprint artwork, font, logo, screenshot, copy or source code is distributed.
`site/assets/workbench-halftone.webp` is original source-owned procedural artwork:
seeded multiscale noise, curved folds, an orange/charcoal/paper palette and an
8x8 ordered print screen. It uses no external image input. The original
`dot-wave-text.tsx` rasterizes the local font and displaces dots through a moving
band, while preserving native text and reduced-motion behavior. No reference
site JavaScript, image or canvas output was downloaded for these implementations.

`site/assets/workbench-texture.svg` is original source-owned gradient and
procedural grain artwork. It has a painted fallback without the grain filter.

Instrument Sans Latin variable WOFF2 is vendored from Google Fonts' official
distribution, linked in `site/assets/licenses/InstrumentSans-SOURCE.md`, under
SIL OFL 1.1. The wordmarks and banner contain outlines from those glyphs. The
README banner contains only the Foundry logo and name. GitHub controls the
font of README Markdown; only the artwork has a project-selected typeface.
