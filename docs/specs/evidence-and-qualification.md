# Evidence, guided journeys, and measured qualification

Approved scope: adapt selected quality, UX, commercial evidence and measured
qualification practices into Foundry's existing runtime. No extra agents, external
framework, vendor analytics, live inference, service signup or deployment.

## Acceptance

- Q1: Optional slice criteria identify a demoable outcome, public interface,
  independent expected result and sensitivity check. Strict red/green evidence
  must bind real nonzero test execution, unchanged test inputs, changed product
  inputs, logs and report hashes. Missing/stale/empty reports cannot pass.
- Q2: Existing records and configured commands remain compatible. A configured
  test-report check fails closed on no tests, invalid counts or a stale report.
- U1: The real local browser exercises review/back/edit, draft resume, invalid
  input, loading, failure/retry and keyboard/mobile focus with retained evidence.
- M1: Optional brief/evidence commercial context records customer/job, dated
  provenance, alternative/workaround, narrow differentiation, channel, activation,
  decision and next review. Synthetic outcomes never become customer validation.
- M2: First successful fixture outline activates an account once, atomically,
  with no PII event payload; failures, retries, restart and tenant boundaries tested.
- E1: Local qualification records candidate, executed evaluation and explicit
  selection separately, with hashes, per-case results and persistent incumbent.
  Repeated candidate registration is idempotent. Missing/invalid/nonfinite results,
  unexecuted probes and stale test/evaluator identity cannot qualify/promote.
- E2: Rejected/blocked candidates preserve the incumbent. Baselines survive process
  restart. Unknown costs remain unknown. Promotion requires an explicit command.
- V1: Meaningful negative/regression sensitivity checks, compatibility exercises,
  independent review and full cold aggregate/browser checks pass. Publish only
  reviewed changes to existing main; hosted CI is separately confirmed.

Use original implementations of the selected practices. Pin and attribute source
inspiration; preserve license notices if any upstream text/code is copied.
