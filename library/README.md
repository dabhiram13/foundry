# Reference skill library

These 67 skills are optional reference material, not installed CLI plugins.
Read the source and license, then copy or adapt only material the project owner
has selected. Foundry does not automatically enable or execute these skills.
See [roles and reference catalog](../docs/CATALOG.md).

Some skills describe a specific provider, framework or external service. For example,
`claude-api` is useful when an application integrates Anthropic's API. Its presence
does not make that provider Foundry's required runtime and does not authorize an
account connection, network call, purchase or deployment.
