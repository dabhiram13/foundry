# Reference skill library

These 67 skills are preserved reference material. They do not run or enter Codex's active skill catalog until enabled. Use `python3 scripts/foundry.py enable-skill NAME`, which refuses to overwrite an existing skill.

Some skills describe a specific provider, framework, or external service. For example, `claude-api` is useful when an application integrates Anthropic's API. Its presence does not make Claude the Product Foundry harness and does not authorize an account connection, network call, purchase, or deployment.
