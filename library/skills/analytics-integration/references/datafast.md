# DataFast

Use when the team wants lightweight product analytics and fast instrumentation without a huge analytics surface.

## Best Fit

- simpler SaaS products
- founder-led teams
- quick insight loops
- lower setup friction than a broad analytics suite

## Start With

- activation event
- core feature usage
- conversion event
- churn-risk or inactivity event if available

## Constraints

- Do not assume feature flags or replay exist.
- Keep the event map tighter than PostHog.

## Setup Later

Collect keys and verify connectivity in `/setup`.
