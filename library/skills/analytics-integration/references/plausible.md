# Plausible

Use when the need is mostly privacy-first website analytics, not deep product analytics.

## Best Fit

- marketing sites
- content sites
- launch pages
- low-complexity products that only need traffic + conversion signals

## Track

- page views
- referrers
- campaign attribution
- main CTA clicks
- signup or checkout redirect clicks

## Avoid

- pretending Plausible is a full product analytics suite
- heavy event trees unless the project really needs them
