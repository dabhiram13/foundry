# Umami

Use when the project wants privacy-friendly analytics with a self-hosted or lightweight posture.

## Best Fit

- teams that want simple website + event analytics
- self-hosted setups
- products that do not need large-scale behavioral tooling yet

## Track

- traffic basics
- key CTA clicks
- signup starts
- simple conversion milestones

## Avoid

- over-instrumenting a lightweight analytics tool
