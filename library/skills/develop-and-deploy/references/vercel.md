# Vercel

Use when the kit is shipping a Next.js app or a straightforward web product and wants the lowest ops burden.

## Best Fit

- Next.js
- landing pages
- SaaS web apps
- fast previews and production deploys

## Default Posture

- use Vercel first
- keep infra simple
- collect tokens, project link info, and env vars in `/setup`

## Existing Assets

- `vercel-cli`
- `vercel-react-best-practices`

## Underlying Skills

- `vercel-cli`
- `project-setup` for token/env collection when needed

## Avoid

- inventing Docker or VPS complexity when Vercel already fits
