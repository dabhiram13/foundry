# Lemon Squeezy

Use Lemon Squeezy when:
- you want simpler hosted billing for software sales
- the product can tolerate a lighter in-app billing surface
- subscriptions and digital product sales matter more than deep billing customization

Good fit:
- smaller SaaS
- creator/dev-tool products
- simpler ownership and hosted checkout preference

Check before choosing:
- does the product need deep custom billing logic?
- does the current app already assume Stripe heavily?
- is simpler hosted checkout more valuable than integration depth?

Setup later:
- API key
- store / product IDs
- webhook signing
- environment values
