# Polar

Use Polar when:
- the product is developer-facing or productized software
- licensing / entitlements are close to the product surface
- you want developer-tool-friendly commercial flows

Good fit:
- dev tools
- productized software
- creator and software sales where entitlement framing matters

Check before choosing:
- are subscriptions enough, or do we also need licensing / entitlements?
- does the product need simpler commerce packaging than full Stripe ownership?

Setup later:
- API key
- organization / product linkage
- webhook config
- env values
