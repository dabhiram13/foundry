# Cormorant Garamond

- Upstream: https://github.com/CatharsisFonts/Cormorant
- Distribution source: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

- License: SIL Open Font License 1.1, retained in `Cormorant-OFL.txt`.
- Local transformation: variable weight instantiated at 600; glyph subset covers
  U+0000–U+024F. Served as a static TTF with `font-display: swap`.
- The SVG wordmark uses outlined glyphs from the same weight. It is typesetting,
