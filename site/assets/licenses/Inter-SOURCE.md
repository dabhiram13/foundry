# Inter

`inter-latin-wght-normal.woff2` is the Latin variable normal font from
`@fontsource-variable/inter` 5.2.8, vendored under the SIL Open Font License 1.1.
The full license is in `Inter-OFL.txt`.

Source: https://www.npmjs.com/package/@fontsource-variable/inter/v/5.2.8
Upstream: https://github.com/rsms/inter

The package tarball's SHA-512 integrity was checked against its npm metadata
before extracting the font and license. No remote font request is needed at run time.
